# color-flip — color-flip

色を合わせてめくる心理戦カードゲーム

## 🔗 リンク

- 遊ぶ: https://t-of.github.io/color-flip/
- 制作: [T.OF...](https://t-of.github.io/)

## 遊び方

あなた＋CPU（計 2〜5 人）。3 ラウンド制で、先に得点 4 か、最後の生き残りがラウンドの勝ち。

- 手番に「引く」「置く（裏向きで 5×5 の盤へ）」「めくる」のどれか 1 つ。チップは手番の最初に 1 枚まで。
- めくったカードの上下左右の表向きと 1 色でも共通なら成功（得点+1、チップを引く）、共通なしなら失敗（体力−1）、隣に表向きがなければ何も起きない。
- 最初の成功者が爆弾を誰かに渡す。持ち主は手番の終わりにカウント−1、0 で体力−1。
- 裏向きの色は置いた本人だけが見える。

## アプリとして入れる（PWA）

- iPhone / iPad: Safari で開き、共有 → 「ホーム画面に追加」
- Android / PC の Chrome・Edge: 画面の「アプリにする」ボタン、またはアドレスバーのインストールボタン

## 開発

ビルド不要。フォルダをそのまま静的サーバで開く。

```sh
python3 -m http.server 8000   # → http://localhost:8000/
```
